# ریموت دسک (Remote Desk)

برنامه ساده ریموت دسکتاپ در **دو نسخه ویندوز و اندروید** با رابط کاربری فارسی.
یک کاربر می‌تواند به رایانه‌ای دیگر وصل شود و صفحه آن را ببیند و کنترل کند؛ اتصال با
**رمز عبور (PIN)** و/یا **تائید دستی کاربر مقصد** انجام می‌شود.

| قابلیت | وضعیت |
| --- | --- |
| دیدن صفحه رایانه از رایانه دیگر | ✓ |
| کنترل ماوس و کیبورد رایانه از رایانه دیگر | ✓ |
| دیدن و کنترل رایانه از گوشی اندروید | ✓ |
| اشتراک صفحه گوشی و دیدن آن از رایانه | ✓ (فقط نمایش — بدون کنترل) |
| احراز هویت با PIN | ✓ |
| تائید/رد دستی هر اتصال | ✓ |
| تنظیم کیفیت تصویر (scale/JPEG) | ✓ |
| تمام‌صفحه، اسکرول، کلیک راست، کلیدهای ویژه | ✓ |

## معماری

- **پروتکل مشترک:** سوکت TCP روی پورت **48500**؛ پیام‌ها با قالب
  `[4 بایت طول][1 بایت نوع][بدنه]` — نوع 1 = JSON کنترلی، نوع 2 = فریم JPEG.
  مختصات ماوس نرمال‌شده (0..1) ارسال می‌شود تا تغییر رزولوشن مقصد کنترل را نشکند.
- **نسخه ویندوز:** Python 3.8+ با Tkinter (رابط فارسی)، mss (گرفتن صفحه)،
  Pillow (رمزگذاری JPEG) و تزریق ورودی با `SendInput` (بدون وابستگی خارجی).
- **نسخه اندروید:** Kotlin، حداقل اندروید ۵ (API 21)، اشتراک صفحه با
  MediaProjection در سرویس پیش‌زمینه.

```
┌──────────────┐   PIN + تائید   ┌──────────────┐
│   نمایشگر    │ ◄──────────────► │    میزبان    │
│ (Viewer)     │   فریم JPEG      │  (Host)      │
│              │ ── ماوس/کیبورد ─►│              │
└──────────────┘                  └──────────────┘
```

## نسخه ویندوز (۸ به بالا)

### نصب

پایتون را از [python.org](https://www.python.org/downloads/) نصب کنید
(روی ویندوز ۸ از **Python 3.8** استفاده کنید؛ ۳٫۹ به بالا فقط ویندوز ۸.۱+ را پشتیبانی می‌کنند).
سپس:

```bat
cd windows
pip install -r requirements.txt
```

### اجرا

```bat
python main.py          :: پنجره انتخاب نقش
python main.py host     :: میزبان (این رایانه اشتراک می‌شود)
python main.py viewer   :: نمایشگر (کنترل رایانه مقصد)
```

**میزبان:** پورت، PIN و حالت اتصال (رمز عبور / تائید دستی / هر دو) را تنظیم و
«شروع اشتراک‌گذاری» را بزنید. آدرس IP نمایش‌داده‌شده را به طرف مقابل بدهید.
هر درخواست اتصال در پنجره تائید نشان داده می‌شود (در حالت تائید دستی).

**نمایشگر:** IP مقصد، پورت، نام و PIN را وارد و «اتصال» بزنید. پس از اتصال،
صفحه مقصد با ماوس و کیبورد کنترل می‌شود. تمام‌صفحه با F11.

### فایروال ویندوز

بار اول که میزبان اجرا می‌شود، ویندوز پنجره فایروال نشان می‌دهد؛ برای
**شبکه‌های خصوصی (Private)** روی Allow بزنید. اگر پنجره را از دست دادید:

```
netsh advfirewall firewall add rule name="RemoteDesk" dir=in action=allow protocol=TCP localport=48500
```

### دریافت نسخه اجرایی (EXE) — بدون نیاز به نصب پایتون

1. به برگه **Actions** همین مخزن بروید و آخرین اجرای «Build Windows EXE» را باز کنید.
2. در پایین صفحه، آرتیفکت **RemoteDesk-Windows-EXE** را دانلود و باز کنید؛ شامل سه فایل است:
   - `RemoteDesk.exe` — لانچر (پنجره انتخاب نقش میزبان/نمایشگر)
   - `RemoteDesk-Host.exe` — مستقیم به‌عنوان میزبان
   - `RemoteDesk-Viewer.exe` — مستقیم به‌عنوان نمایشگر
3. هر فایل EXE تک‌فایلی و مستقل است و روی ویندوز ۸ به بالا اجرا می‌شود (بیلد با Python 3.8).

> ⚠️ اگر Windows SmartScreen فایل را نگه داشت، «More info → Run anyway» بزنید؛
> چون فایل امضای دیجیتال ندارد، ممکن است آنتی‌ویروس‌ها اخطار اولیه بدهند.

## نسخه اندروید

### دریافت APK آماده

1. به برگه **Actions** همین مخزن بروید و آخرین اجرای «Build Android APK» را باز کنید.
2. در پایین صفحه، آرتیفکت **RemoteDesk-debug-APK** را دانلود کنید.
3. فایل را روی گوشی نصب کنید (اجازه «نصب منابع ناشناس» را بدهید).

### بیلد دستی

با Android Studio پوشه `android/` را باز کنید و Run بزنید، یا خط فرمانی:

```bash
cd android
./gradlew :app:assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

### حالت نمایشگر (گوشی → رایانه)

1. در برنامه «اتصال به رایانه (نمایشگر)» را بزنید.
2. IP رایانه، پورت (48500) و PIN را وارد و «اتصال» بزنید.
3. **حرکات:**
   - لمس/کشیدن با یک انگشت = ماوس چپ (لمس کوتاه = کلیک)
   - لمس طولانی = کلیک راست
   - کشیدن عمودی با دو انگشت = اسکرول
   - دکمه «کیبورد» = تایپ متن، Enter/Backspace/Esc/جهت‌ها و نگه‌داشتن Ctrl/Alt/Shift

### حالت میزبان (گوشی → نمایش از رایانه)

1. «اشتراک‌گذاری صفحه گوشی (میزبان)» را بزنید.
2. PIN نمایش‌داده‌شده را به رایانه بدهید و «شروع اشتراک‌گذاری» را بزنید
   (اجازه MediaProjection را بدهید).
3. در نسخه ویندوز، نمایشگر را به IP گوشی و پورت 48500 وصل کنید.
4. اگر «هر اتصال با تائید من» فعال باشد، هر درخواست با پنجره تائید/رد بررسی می‌شود.

> ⚠️ **محدودیت:** اندروید به برنامه‌های عادی اجازه تزریق لمس از بیرون را نمی‌دهد
> (نیازمند Root یا AccessibilityService است)، بنابراین در حالت میزبانی گوشی،
> رایانه فقط **نمایش‌دهنده** است و ماوس/کیبورد رایانه اثری روی گوشی ندارد.
> این محدودیت در خود برنامه هم پیام داده می‌شود.

## امنیت

- این نسخه برای **شبکه محلی (LAN)** طراحی شده و ترافیک **رمزنگاری نمی‌شود**؛
  برای استفاده از راه دور روی اینترنت حتماً از VPN (مثلاً WireGuard/Tailscale) استفاده کنید.
- PIN با مقایسه زمان-ثابت بررسی می‌شود و درخواست تائید‌نشده رد می‌شود.
- PIN را بعد از هر جلسه با دکمه «بازتولید» عوض کنید.
- سرور بدون PIN فعال نمی‌شود مگر حالت «تائید دستی» انتخاب شده باشد؛
  اگر هیچ‌کدام فعال نباشد، اتصال‌ها رد می‌شوند (fail-safe).

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| اتصال برقرار نمی‌شود | فایروال پورت 48500 را باز کنید؛ IP مقصد را با `ipconfig` / `ip addr` چک کنید؛ هر دو دستگاه در یک شبکه باشند |
| صفحه سیاه است در میزبانی گوشی | اشتراک را دوباره شروع کنید؛ چرخش صفحه گوشی در این نسخه پشتیبانی نمی‌شود — گوشی را قبل از اتصال بچرخانید و مجدد شروع کنید |
| تصویر کند است | کیفیت را «کم» بگذارید (نمایشگر ویندوز) یا مقیاس صفحه را کم کنید (میزبان ویندوز) |
| «رمز نادرست است» | PIN را دوباره از پنجره میزبان چک کنید |
| روی ویندوز ماوس/کیبورد کار نمی‌کند | برنامه را «Run as administrator» اجرا کنید تا ورودی به پنجره‌های سطح ادمین هم برسد |
| گوشی اتصال را نمی‌پذیرد | اگر اکتیویتی میزبانی بسته باشد، درخواست تائید بعد از ۴۵ ثانیه خودکار رد می‌شود — صفحه میزبانی را باز نگه دارید |

## ساختار پروژه

```
windows/        نسخه ویندوز (Python)
  protocol.py     پروتکل پیام
  capture.py      گرفتن صفحه با mss
  input_inject.py تزریق ماوس/کیبورد با SendInput
  host_server.py  سرور میزبان (auth + فریم + دستورات)
  host_app.py     GUI میزبان
  viewer_app.py   GUI نمایشگر
  main.py         لانچر
android/        نسخه اندروید (Kotlin)
  Net.kt          پروتکل مشترک
  ViewerClient.kt / ViewerActivity.kt / ScreenView.kt   نمایشگر
  HostService.kt / HostActivity.kt                      میزبان (MediaProjection)
.github/workflows/android-build.yml   بیلد خودکار APK
```

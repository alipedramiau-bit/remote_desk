# ریموت دسک — نسخه ویندوز

پیش‌نیاز: **Python 3.8 به بالا** (روی ویندوز ۸ از Python 3.8 استفاده کنید؛ روی ویندوز ۱۰/۱۱ آخرین نسخه هم قابل استفاده است).
Tkinter همراه پایتون نصب است.

## نصب

```bat
cd windows
pip install -r requirements.txt
```

## اجرا

```bat
python main.py          :: پنجره انتخاب نقش
python main.py host     :: میزبان (این رایانه اشتراک می‌شود)
python main.py viewer   :: نمایشگر (کنترل رایانه مقصد)
```

### میزبان
1. «شروع اشتراک‌گذاری» را بزنید.
2. حالت اتصال را انتخاب کنید: **رمز عبور** (PIN)، **تائید دستی** (هر درخواست با پنجره تائید نمایش داده می‌شود) یا **هر دو**.
3. آدرس IP و پورت نمایش‌داده‌شده را به طرف مقابل بدهید.
4. درخواست‌های اتصال در همین پنجره تائید/رد می‌شوند.

> اولین بار ویندوز فایروال را نشان می‌دهد؛ برای پورت 48500 روی شبکه خصوصی **Allow** بزنید.

### نمایشگر
1. آدرس IP مقصد، پورت، نام و (در صورت فعال بودن رمز) PIN را وارد کنید.
2. «اتصال» — اگر تائید دستی فعال باشد باید کاربر مقصد پذیرش کند.
3. صفحه مقصد نمایش داده می‌شود؛ ماوس و کیبورد به مقصد منتقل می‌شوند.
4. تمام‌صفحه با F11 یا دکمه نوار ابزار؛ قطع اتصال با دکمه «قطع اتصال».
